These files are product screenshots, not generated interface mockups. They have been inspected before being added to the public portfolio and optimized as WebP.

- `flowstudio-editor.webp`, `flowstudio-overview.webp`: existing local screenshots of Flowstudio's example research workflow and workspace. No provider configuration or private project content is shown.

Only rendered product views are included. Source files and private runtime data are not distributed with these captures.
