# Portfolio Website Template

A clean, responsive one-page portfolio template built with plain HTML, CSS, and
JavaScript. It is ready to customize with your own name, projects, skills, and
contact links.

## What is included

- Responsive hero, about, skills, projects, experience, and contact sections
- Mobile navigation menu
- Active navigation link highlighting while scrolling
- CSS variables for quick color and layout customization
- No build tools or dependencies required

## Preview locally

Open `index.html` directly in your browser, or serve the folder with any static
file server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

1. Replace `Your Name`, `YN`, and role placeholders in `index.html`.
2. Update the project cards with your real project names, links, and outcomes.
3. Edit the skills and experience sections to match your background.
4. Replace the email, LinkedIn, and GitHub URLs in the contact section.
5. Adjust colors in `styles.css` under the `:root` selector.
